# 設計參考規格 (Design Spec)

> 來源:使用者於 2026-08-24 提供之設計參考圖 (`docs/design-reference.png`)
> 本檔為 UI 實作的唯一視覺基準,任何分歧需對齊此處。

## 1. 品牌基調

- **主標題**:餐飲點餐快手(英:Smart Dining Self-Ordering & Tracking System)
- **副標題**:點餐、取餐、會員回訪一次完成
- **主色**:橘紅 #FF6B35(餐飲活力,CTA、按鈕強調)
- **輔色**:深綠 #2D6A4F(已完成狀態、健康)
- **強調色**:金 #FFB627(VIP / 等級徽章)
- **中性色**:深灰 #1F2937(標題)、中灰 #6B7280(副文)、淺灰 #F3F4F6(背景)
- **字體**:Noto Sans TC(系統字 fallback)
- **圓角**:12-16px(按鈕、卡片),20px(主要容器)
- **陰影**:soft shadow, e.g. `0 4px 20px rgba(0,0,0,0.08)`

## 2. KIOSK 平板介面 (1024 × 768 直式)

### 2.1 整體版面 (單頁 Dashboard,不走多頁 routing)
三欄式 + 底部客製化面板:

| 區塊 | 寬度 | 內容 |
|------|------|------|
| 左側導航欄 | 14% (~140px) | 7 個分類 + 底部「取餐進度」CTA |
| 中央菜單區 | 50% | 兩列「推薦餐點」橫向卡片 |
| 右側購物車 | 22% (~220px) | 我的餐點清單 + 小計 + 前往結帳 |
| 底部客製化面板 | 100% 全寬 | 主食 / 醬料 / 加購三群組 chips |

### 2.2 左側導航欄內容(由上至下)
1. 🍱 推薦餐點(active,深底白字)
2. 🌟 人氣精選
3. 🍚 主餐
4. 🍟 配餐
5. 🥤 飲品
6. 🍰 甜點
7. 👤 會員專區
(底部固定) 取餐進度 CTA(連結到 modal 或頁內 panel)

### 2.3 中央菜單區
- 標題列:「推薦餐點」(24px,粗體) + 右側「查看全部」
- 第一列 3 張大卡:品項大圖(約 200×140)、名稱、$價格、「+」加入按鈕
  - 經典脆雞 $149 / 花生牛肉堡餐 $179 / 泰式椒麻雞餐 $169
- 第二列小卡:塔香脆雞 $149 / 可樂(中) $30 / 薯條 $30
- 加入按鈕 hover/active 狀態為橘色填充

### 2.4 右側購物車
- 標題「我的餐點」+ 右上角「清空」(icon)
- 品項列:小圖、名稱、單價、數量 +/-、移除
- 底部:小計 $XXX(粗體大字)+ 「前往結帳 →」CTA(深色 filled)
- 空狀態:顯示插圖 + 「尚未選擇餐點」

### 2.5 底部客製化面板(展開式,占全寬 25%)
- 標題「客製化選項」(展開時顯示目前選中的品項名稱)
- 三個群組 chips(SINGLE 為 radio 樣式,MULTI 為 checkbox 樣式):
  - **主食選擇**(SINGLE):白飯(已選,黑底白字)/ 冬粉 / 玉米蛋堡 +$10
  - **醬料選擇**(SINGLE):醬油(已選)/ 辣油 / 蒜香 / 橄欖油
  - **加購**(MULTI):薯條 +$30 / 雞塊(6pc) +$49 / 可樂(中) +$15
- 每個 chip 含名稱與加價,選中時深底白字

### 2.6 完成畫面(結帳後,全螢幕覆蓋)
- 取餐號碼 A128(120-160px,橘底白字,圓角卡片)
- 訂單編號(SD-YYYYMMDD-XXXX)副標
- 預計取餐時間 12:24(大字)
- QR code(80×80,內容 `{WEB}/track/{orderNo}`)
- 「列印取餐單」+「新訂單」雙按鈕

## 3. 行動 APP 介面 (375 × 812 直式, PWA)

### 3.1 整體設計語言
- 行動優先,bottom safe-area 預留
- 卡片式,白底 + soft shadow
- 底部導航 3 tab:取餐 / 會員 / 訂單(icon + 文字)

### 3.2 取餐進度頁(TrackPage + OrderDetailPage 合一)
- **頂部 Header**:標題「取餐進度」+ 返回箭頭
- **取餐號碼卡**(橘底白字,圓角 20px):
  - 標籤「取餐號碼」(小字)
  - 號碼 A128(96px,粗體)
- **預計時間**:
  - 「預計 12:24 可取餐」(28px)
  - 倒數計時(每分鐘更新)
- **進度時間軸**(垂直):
  - 已接單 ✓ (綠勾,時間 11:55)
  - 製作中 → (橘色高亮 + 脈動動畫,時間 12:10)
  - 已完成 ○ (灰色,待觸發)
- **會員優惠 CTA**(滿版卡片,淺橘底):
  - 「VIP 會員獨享 9 折」+ 「查看優惠券」按鈕
- **訂單明細**(摺疊區):
  - 品項列表(名稱、客製化摘要、數量、單價)
  - 小計 / 折扣 / 總計

### 3.3 會員頁(MemberPage)
- 大頭貼 placeholder(顯示會員姓名前兩字,橘底白字)+ 姓名(24px)
- 等級徽章:VIP 金 / 一般 灰
- 點數大字(72px)+ 「= NT$ XX 可折抵」
- 兩個 CTA 卡片:查看優惠券 / 訂單歷史

### 3.4 訂單歷史頁(HistoryPage)
- 訂單卡片列表:訂單編號、取餐號、日期、總金額、狀態 chip
- 點擊進入取餐進度頁(同 3.2 結構)

## 4. Hero / 登陸頁 (marketing web)

雖然本期未實作,但設計稿有 hero 區塊,作為未來行銷頁基礎:

- 滿版背景:餐廳現場照片(模糊處理)
- 左側 KIOSK 平板大圖
- 右下手機浮層
- 右側文字:
  - 餐飲點餐快手(80px)
  - 點餐、取餐、會員回訪一次完成(36px)
  - 三個 icon 卡片:自助點餐 / 取餐進度 / 會員優惠

## 5. 互動細節

- **加入購物車**:按鈕按下時 scale 0.95 動畫,然後彈回
- **選中 chip**:背景由灰轉橘(transition 200ms)
- **取餐號碼出現**:號碼從 0 滾動到實際號碼的 1.5s 動畫
- **進度推進**:新階段時對應 chip 脈動 2 次
- **READY 通知**:WebSocket 收到 `order:ready` 時,整頁背景閃橘光 1 次 + navigator.vibrate

## 6. 無障礙

- 所有按鈕 ≥ 48×48 觸控目標
- 色彩對比 ≥ WCAG AA
- 鍵盤可達(雖然主要為觸控)
- 取餐號碼提供 aria-label
